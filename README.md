# 💰 Expense Tracker

A simple and user-friendly **Expense Tracker** built with **HTML, CSS, and JavaScript**.
It helps users keep track of their income and expenses and shows the current balance.

## 🚀 Features

* ➕ Add income transactions
* ➖ Add expense transactions
* 💵 Automatically calculate current balance
* 📊 Display total income and total expenses
* 🗑️ Delete transactions
* 🔄 Update balance automatically
* 📱 Simple and responsive interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## 📂 Project Structure

```text
Expense-Tracker/
│

```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding your income and expenses.

## 🎯 Purpose

This project was created to practice **JavaScript, DOM manipulation, event handling, and basic financial calculations**.
